### Packages (Basecamp 0.2.3)

| File | What it is |
|---|---|
| `logos-poker-module-lib.lgx` | `poker` core module, macOS arm64 + Linux x86_64 |
| `logos-poker_ui-module.lgx` | `poker_ui` table UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Modules → Install LGX Package**.

### Fixes
- **The hand no longer depends on the "start" message arriving.** Across the Logos fleet, the dealer's small "start" message kept going missing, even when resent, while the shuffle sent right after it arrived. The dealer's first shuffle now carries the hand details as well, so other players can join the hand from it.
- **Messages are sent one at a time**, 120 ms apart, instead of in bursts.

Includes the fixes from v0.2.2 and v0.2.3.

### Known limitations
- Not yet confirmed in a full game across two machines.
- No verifiable-shuffle proof; peers are assumed to follow the protocol.
- The Linux packages are built in CI and haven't been tried in Basecamp on Linux.
