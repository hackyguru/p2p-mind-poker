### Packages (Basecamp 0.2.3)

| File | What it is |
|---|---|
| `logos-poker-module-lib.lgx` | `poker` core module, macOS arm64 + Linux x86_64 |
| `logos-poker_ui-module.lgx` | `poker_ui` table UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Modules → Install LGX Package**.

### Fixes
- **Stable node identity.** v0.2.1 gave every launch a brand-new random node key. Relaunching repeatedly from one IP (for example two instances on one computer) piled up connections at the Logos fleet nodes, which then started dropping that IP. The key is now generated once per install (per P2P port) and reused.

Includes everything from [v0.2.2](https://github.com/hackyguru/p2p-mind-poker/releases/tag/v0.2.2): resending stalled hand messages, abandoning dead hands with a refund, and dealing in only players who are still online.

### Known limitations
- Right after upgrading, the first launch still uses a new identity; if the fleet refuses it, wait a few minutes and start the network again.
- No verifiable-shuffle proof; peers are assumed to follow the protocol.
- The Linux packages are built in CI and haven't been tried in Basecamp on Linux.
