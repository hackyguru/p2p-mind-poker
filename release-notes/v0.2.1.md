**Everyone at the table needs v0.2.1.** Earlier builds can't see players on other computers.

### Packages (Basecamp 0.2.3)

| File | What it is |
|---|---|
| `logos-poker-module-lib.lgx` | `poker` core module, macOS arm64 + Linux x86_64 |
| `logos-poker_ui-module.lgx` | `poker_ui` table UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Modules → Install LGX Package**. Verify downloads with `sha256sum -c SHA256SUMS`.

### Fixes
- **Every node gets its own identity.** All installs used one built-in node key, so every computer was the same peer on the network.
- **Connects to the right network cluster.** The `logos.dev` fleet moved to cluster 3, but Basecamp 0.2.3's delivery module still puts that preset on cluster 2, so the fleet disconnected every node. The module now configures cluster 3 itself (`POKER_PRESET=<name>` uses a stock preset instead).
- The two-instances-on-one-machine test is now opt-in with `POKER_INSTANCE=A` / `POKER_INSTANCE=B`.

### Known limitations
- A full hand between two machines hasn't been observed yet; players seeing each other across networks has.
- No verifiable-shuffle proof; peers are assumed to follow the protocol.
- A peer that quits Basecamp mid-hand stalls the hand (no timeouts yet).
- The Linux packages are built in CI and haven't been tried in Basecamp on Linux.
