### Packages

| File | What it is |
|---|---|
| `logos-poker-module-lib.lgx` | `poker` core module, **macOS arm64 + Linux x86_64** in one package |
| `logos-poker_ui-module.lgx` | `poker_ui` table UI, **macOS arm64 + Linux x86_64** in one package |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from Basecamp's **Modules → Install LGX Package**. Verify downloads with `sha256sum -c SHA256SUMS`.

### What's new
- **Poker-table UI**: oval felt table with a wooden rail, players seated around it, fanned hole cards, bets, dealer button, pot and winner banner in the middle, and betting controls along the bottom.
- **Hand-rankings cheat sheet**: a side panel with all ten hands and example cards; the winning hand type is highlighted after each hand.
- **Linux builds** alongside macOS, built on GitHub Actions.
- Seats no longer cover the board in narrow windows.
- A full hand has now been played from shuffle to showdown across two Basecamp instances.

### Known limitations
- No verifiable-shuffle proof; peers are assumed to follow the protocol.
- A peer that quits Basecamp mid-hand stalls the hand (no timeouts yet).
- The built-in two-peer setup targets two instances on one machine.
- The Linux packages are built in CI and have not yet been tried in Basecamp on Linux.
