### Packages (Basecamp 0.2.3)

| File | What it is |
|---|---|
| `logos-poker-module-lib.lgx` | `poker` core module, macOS arm64 + Linux x86_64 |
| `logos-poker_ui-module.lgx` | `poker_ui` table UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Modules → Install LGX Package**.

### Fixes
- **Stalled hands resend their messages.** The relay network occasionally drops a message and never redelivers it. A lost "start" left everyone stuck on "Shuffling deck". When a hand stops moving for 4 seconds, each player now re-sends what they sent for it, up to 3 times.
- **Dead hands are abandoned with a refund.** After 60 s without progress during the shuffle, 30 s if a player stops responding, or 3 minutes during betting, the hand is dropped, every stack goes back to its starting amount, and the table says why. The host can then deal again.
- **Only live players are dealt in.** Players must have been heard from in the last 15 seconds. Seats whose Basecamp has closed are removed after 30 seconds.

### Known limitations
- These fixes haven't yet been tested in a game across two machines.
- No verifiable-shuffle proof; peers are assumed to follow the protocol.
- The Linux packages are built in CI and haven't been tried in Basecamp on Linux.
